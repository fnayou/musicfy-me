# MusicfyMe

![MusicfyMe banner: a vinyl disc inside a circular arrow, with the tagline "Save, sync, export and restore your music playlists across streaming platforms."](brand/generated/readme-banner.svg)

Save, sync, export and restore your music playlists across streaming platforms (Apple Music, Spotify).

## Getting started

Install [Task](https://taskfile.dev/) and run `task setup`, then `task doctor`.

## Commands

Run `task --list` for available commands.

## Project profile

This repository is initialized as a POC foundation. Add verified project-specific build and test instructions as the implementation takes shape.

## Contributing and security

See [CONTRIBUTING.md](CONTRIBUTING.md), [SECURITY.md](SECURITY.md), and [SUPPORT.md](SUPPORT.md).

## Docker Compose

Run `task setup` to create ignored `compose.yaml` from the tracked example when it is missing. Edit the local file for machine-specific settings. Run `task docker:config` to validate the example.
